未接続

接続情報はこのブラウザー内にのみ保存されます。共有端末での保存は避けてください。

接続の手順

  1. Home AssistantをHTTPSでインターネットまたはローカルネットワークに公開します。
  2. Home Assistantのプロフィールから長期アクセストークンを発行します。
  3. 上の欄にURLとトークンを入力して接続します。

GitHub PagesはHTTPSで配信されます。Home Assistant側もHTTPSでアクセスできるURLをご利用ください。別オリジンから接続する場合、Home AssistantでGitHub PagesのURLをCORS許可する必要があります。

Google Homeでも使う

Home Assistant CloudまたはGoogle Assistant連携を設定すると、同じ機器を「OK Google」対応端末とこのアプリの両方から操作できます。
